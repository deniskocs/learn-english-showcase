Политика конфиденциальности

Последнее обновление: 27 ноября 2025 г.

1. Общая информация

Приложение Learn English использует данные пользователя только для работы основных функций приложения.

2. Собираемые данные

Приложение может собирать следующие данные:

  • Аудиозаписи речи через микрофон (android.permission.RECORD_AUDIO) для транскрибации и анализа произношения.
  • Текст, который пользователь вводит в приложении.
  • Данные аутентификации Google (имя и email) при входе через Google Sign-in.
  • Пользовательский словарь и прогресс обучения.

3. Использование данных

Собранные данные используются для:

  • транскрибации аудио;
  • анализа произношения и подбора слов;
  • формирования личного словаря;
  • обеспечения работы функций приложения.

4. Передача данных третьим лицам

Мы не передаём персональные данные третьим лицам.

Исключения:

  • вход через Google Sign-in в соответствии с политикой Google;
  • анонимная аналитика использования приложения.

5. Контроль и удаление данных

Пользователь может удалить свои данные и записи через интерфейс приложения.

Отключение доступа к микрофону возможно через настройки устройства.

6. Контакты

По вопросам конфиденциальности можно связаться через приложение.
